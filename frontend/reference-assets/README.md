# Aset referensi pengembangan

Arsip unduhan sementara dan karakter alternatif disimpan di sini karena tidak
digunakan aplikasi. Folder ini berada di luar `public`, sehingga Vite tidak
menyalinnya ke hasil build. Sumber tetap dipertahankan untuk referensi.

Avatar aktif, robot opsional, preview aktif, dan atribusi tetap berada di
`public/models`. Pemindahan ini mengurangi keluaran build sebesar 46.892.495 byte.
